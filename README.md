# nixos-config

Flake-based NixOS configuration (`flake.nix`) plus a sibling nix-darwin
configuration for Macs under `darwin/` (see `darwin/flake.nix`). This README
covers bootstrapping a **NixOS** machine from scratch; for Macs, run
`darwin-rebuild switch --flake ./darwin#<host>` from a checkout instead.

## Repo layout

```
flake.nix                        NixOS flake: nixosConfigurations.<host>
hosts/<host>/configuration.nix   per-machine system config
hosts/<host>/hardware-configuration.nix   generated by nixos-generate-config, unique per machine
home/common.nix                  home-manager settings shared by every host
home/linux.nix                   home-manager settings for NixOS hosts
```

Currently the only NixOS host defined is `gamix` (`hosts/gamix/`).

## Installing on a brand new machine

### 1. Boot the NixOS installer and partition the disk

Boot the official NixOS ISO, then partition/format/mount the target disk at
`/mnt` as usual (see the [NixOS manual](https://nixos.org/manual/nixos/stable/#sec-installation-partitioning)
for `fdisk`/`parted` + `mount` steps). This repo does not include a disko
config, so partitioning is manual.

### 2. Generate the hardware config

```
nixos-generate-config --root /mnt
```

This writes `/mnt/etc/nixos/hardware-configuration.nix`, which describes the
disk layout, filesystems, and kernel modules for *this specific machine*.
Keep this file — you'll drop it into the repo in step 4.

### 3. Get this repo onto the new machine

```
nix-shell -p git --run "git clone git@github.com:arnestorksen/nix-darwin.git /mnt/home/arne/nixos-config"
```

(The remote is still named `nix-darwin` on GitHub — it predates this repo
and also holds the `darwin/` nix-darwin config for two Macs — but the local
clone is named `nixos-config` to match.)

(Installer images don't have `git` by default — `nix-shell -p git` pulls it
in temporarily.) Otherwise copy the working tree over some other way (USB
stick, `scp`, etc.).

### 4. Wire up the host

- **Reinstalling `gamix` on the same or equivalent hardware:** copy the
  hardware config you just generated over the repo's copy:
  ```
  cp /mnt/etc/nixos/hardware-configuration.nix /mnt/home/arne/nixos-config/hosts/gamix/hardware-configuration.nix
  ```
- **A genuinely new host:** create `hosts/<new-host>/configuration.nix` and
  `hosts/<new-host>/hardware-configuration.nix` (the one from step 2), then
  add a matching `nixosConfigurations.<new-host>` block in `flake.nix`
  (copy the `gamix` block and adjust `system`, the imported `configuration.nix`
  path, and the `home-manager.users.<user>` line). Also add a `home/<new-host>.nix`
  if its home-manager setup should differ from `home/linux.nix`.

### 5. Install

From the installer environment:

```
nixos-install --flake /mnt/home/arne/nixos-config#gamix --root /mnt
```

(Swap `gamix` for the new host's attribute name if applicable.) `nixos-install`
needs flakes enabled for this invocation — pass
`--extra-experimental-features 'nix-command flakes'` if the installer image
doesn't have them on by default.

Set a root password when prompted, then `reboot`.

### 6. First boot

Log in as `arne`, set a password (`passwd`), and confirm the home-manager
profile (packages from `home/linux.nix`) came up correctly — it activates
automatically as part of the same `nixos-install`/`nixos-rebuild` run since
`home-manager.nixosModules.home-manager` is wired into `flake.nix` directly,
there's no separate `home-manager switch` step needed.

### 7. Future rebuilds

From the repo checkout on the running machine:

```
sudo nixos-rebuild switch --flake .#gamix
```
